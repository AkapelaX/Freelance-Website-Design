BILLING & OWNERSHIP

Simple subscription access. Permanent website ownership.

Your Bluvixa subscription and website buyouts are separate so customers always know exactly what they are paying for.

1 BLUVIXA SUBSCRIPTION

Build and manage websites

Your subscription gives you access to the builder, saved projects, drafts, cloud tools, publishing controls, and account features.

  • Build as many draft websites as you need.
  • Your selected plan controls the features available inside each website.
  • Canceling the subscription ends platform access after the paid period.
  • A subscription does not automatically transfer raw-code ownership.
Current planNo active planNot subscribedRenewal information unavailable
2 WEBSITE BUYOUT

Own a specific finished website forever

A buyout is a one-time Stripe purchase attached to one website project. It unlocks that website’s downloadable code package permanently.

  • Starter website buyout: $499
  • Professional website buyout: $599
  • Advanced website buyout: $699
  • Buying one website does not buy every website in the account.
Choose a Website to Buy Out

What happens after a buyout?

Ownership saved permanently

The website record stays marked as owned even if the subscription later ends.

Export unlocked

The Saved Drafts page displays Download ZIP for that purchased website.

Continue editing

While subscribed, you can continue editing and create later snapshots of the purchased site.

Hosting is separate

Code ownership does not automatically include permanent hosting, domain registration, or future platform service.
